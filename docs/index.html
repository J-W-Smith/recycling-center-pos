Voids

Controlled workflow

1. Permission Check

Void requires manager/admin role. Plain operators cannot void completed transactions.

2. Manager PIN

Manager PIN confirmation is required. PIN values are never logged in this demo or the MVP.

3. Reason Required

The approver must enter a reason such as wrong material, duplicate ticket, or payout correction.

4. Audit Logged

The original receipt is preserved, the transaction is marked voided, and the action is audit logged.

Voided totals are excluded from normal payout totals and shown separately in reports.
